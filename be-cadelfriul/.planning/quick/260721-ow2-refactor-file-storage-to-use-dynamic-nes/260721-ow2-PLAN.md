**FileStorageService.java** (core.service package):
- Constructor accepts `@Value("${app.storage.base-dir:uploads}")` for the base directory
- Method: `String storeFile(String domain, UUID entityId, byte[] fileData, String contentType, String originalFilename)`
  - Creates directory: `{baseDir}/{domain}/{entityId}/`
  - Generates unique filename: `UUID.randomUUID() + "_" + originalFilename`
  - Writes bytes to disk
  - Returns the relative URL path: `/api/{domain}/images/{uniqueFilename}`
- Method: `Resource loadFile(String domain, UUID entityId, String filename)`
  - Resolves path: `{baseDir}/{domain}/{entityId}/{filename}`
  - Returns UrlResource if exists, null otherwise
- Method: `void deleteFile(String domain, UUID entityId, String filename)`
  - Deletes file if exists
