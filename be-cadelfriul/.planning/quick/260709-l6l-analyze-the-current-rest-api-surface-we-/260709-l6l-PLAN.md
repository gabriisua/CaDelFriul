# Quick Task 260709-l6l: Secure Customer List + Enhance Public Product Queries

**Date:** 2026-07-09
**Mode:** quick

## Task 1: Secure CustomerController.findAll with Admin role check

**Files:**
- `src/main/java/com/cadelfriul/backend/core/config/JwtAuthenticationFilter.java`
- `src/main/java/com/cadelfriul/backend/core/auth/controller/CustomerController.java`

**Action:**
1. In `JwtAuthenticationFilter`, extract the `role` claim from the JWT token and set it as a `SimpleGrantedAuthority("ROLE_" + role)` on the `UsernamePasswordAuthenticationToken`. Admins have `"role": "ADMIN"` in their JWT claims, customers have `"role": "CUSTOMER"`.
2. In `CustomerController.findAll()`, add `@PreAuthorize("hasRole('ADMIN')")` so only admin users can list all customers.

**Verify:**
- `GET /api/customers` with a customer JWT returns 403 Forbidden
- `GET /api/customers` with an admin JWT returns 200 with customer list
- Existing customer-owned endpoints (`findById`, `update`, `delete`) still work via `validateOwnership`

## Task 2: Enhance PublicProductController with optional filters

**Files:**
- `src/main/java/com/cadelfriul/backend/core/ecommerce/controller/PublicProductController.java`
- `src/main/java/com/cadelfriul/backend/core/ecommerce/service/PublicProductService.java`
- `src/main/java/com/cadelfriul/backend/core/ecommerce/repository/ProductRepository.java`

**Action:**
1. Add query parameters to `PublicProductController.getAvailableProducts()`:
   - `categoryId` (UUID, optional)
   - `search` (String, optional - searches name and description)
   - `minPrice` (BigDecimal, optional)
   - `maxPrice` (BigDecimal, optional)
2. Update `PublicProductService.getAvailableProducts()` to accept all filter parameters.
3. Implement a custom `@Query` or `Specification` in `ProductRepository` that dynamically filters:
   - `isAvailable = true` (always)
   - `categoryId` if non-null
   - name OR description ILIKE `%search%` if search is non-null
   - price >= minPrice if non-null
   - price <= maxPrice if non-null

**Verify:**
- `GET /api/products` returns all available products (backward compatible)
- `GET /api/products?categoryId=...` filters by category
- `GET /api/products?search=foo` searches name and description
- `GET /api/products?minPrice=10&maxPrice=100` filters by price range
- Combination of all params works together
