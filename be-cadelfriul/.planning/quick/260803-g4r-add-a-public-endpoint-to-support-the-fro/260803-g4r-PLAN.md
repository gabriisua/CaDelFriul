     ```java
     static List<LocalDate> expandBookedDates(List<RoomReservation> reservations) {
         // for each reservation: iterate LocalDate d = checkInDate; d.isBefore(checkOutDate); d = d.plusDays(1)
         // (ChronoUnit.DAYS.between for the count, then plusDays loop), collecting into a java.util.TreeSet<LocalDate>
         // (TreeSet gives sorted + de-duplicated), return new ArrayList<>(treeSet)
         // DO NOT touch reservation.getRoom() — it is LAZY; the query already filtered by room.id
     }
     ```
     The loop must treat `checkInDate` as inclusive and `checkOutDate` as exclusive (a 10→13 reservation yields 10, 11, 12 — 3 nights). Overlapping reservations must contribute the same dates once (TreeSet dedup). Input order must not matter (TreeSet sorts).
   - A `@Transactional(readOnly = true)` method:
     ```java
     @Transactional(readOnly = true)
     public List<LocalDate> getBookedDates(UUID roomId) {
         return expandBookedDates(roomReservationRepository.findByRoom_IdAndStatus(roomId, ReservationStatus.CONFIRMED));
     }
     ```
     Per D-04: unknown roomId / no CONFIRMED reservations → empty list from the query naturally. No `RoomRepository` lookup, no 404.
   - Required imports: `java.time.LocalDate`, `java.util.ArrayList`, `java.util.TreeSet` (add to the existing `java.util.List` / `java.time.temporal.ChronoUnit` imports already present; `ChronoUnit` is already imported). `ReservationStatus` is already imported.
