<objective>
Eliminate duplicate `/api/auth/me` calls by introducing a shared React Context (AuthProvider + useAuth hook) that calls fetchProfile once and provides user state to all dashboard components.

**Purpose:** Currently SidebarNav and ProfilePage each call fetchProfile independently on mount, causing duplicate API calls. Centralizing auth state in context deduplicates these calls and provides a single source of truth for user identity.

**Output:**
- `src/context/AuthContext.tsx` — AuthProvider + useAuth hook
- Updated `DashboardLayout.tsx` — wraps content with AuthProvider (becomes "use client")
- Updated `SidebarNav.tsx` — consumes useAuth instead of local fetchProfile
- Updated `profile/page.tsx` — consumes useAuth for user.id, fetches customer details via context
</objective>

<interfaces>
From `src/lib/api.ts`:
```typescript
export interface UserResponse {
  id: string;
  firstName: string;
  lastName: string;
  email: string;
  phone?: string;
}

export interface CustomerDetails {
  id: string;
  firstName: string;
  lastName: string;
  email: string;
  phone: string;
}

export function fetchProfile(): Promise<UserResponse>;
export function fetchCustomerDetails(customerId: string): Promise<CustomerDetails>;
export function logout(): Promise<void>;
```

**AuthContext contract (to be created):**
```typescript
// AuthContext provides this shape to consumers
interface AuthContextValue {
  user: UserResponse | null;
  loading: boolean;
}

// Hook — throws if used outside AuthProvider
function useAuth(): AuthContextValue;
```
</interfaces>

**Existing component relationships:**
- `dashboard/layout.tsx` (server) → renders `<DashboardLayout>` (client)
- `DashboardLayout.tsx` → renders `<SidebarNav>` + `<main>{children}</main>
- `SidebarNav.tsx` — currently calls `fetchProfile()` in useEffect, has local `[user, setUser]`, `[profileLoading, setProfileLoading]`
- `profile/page.tsx` — currently chains `fetchProfile() → fetchCustomerDetails(id)` in useEffect with cancelled guard

After this plan:
- `DashboardLayout.tsx` wraps everything with `<AuthProvider>`
- `SidebarNav.tsx` removes local fetchProfile, uses `useAuth()`
- `profile/page.tsx` removes local fetchProfile, gets `user.id` from `useAuth()`, triggers `fetchCustomerDetails(user.id)` on id change

         if (!authUser?.id) return;
         let cancelled = false;
         setCustomerLoading(true);
         fetchCustomerDetails(authUser.id)
           .then((data) => {
             if (cancelled) return;
             setCustomer(data);
             setFirstName(data.firstName);
             setLastName(data.lastName);
             setPhone(data.phone);
           })
           .catch(() => {
             if (!cancelled) setError("Could not load profile data.");

           .finally(() => {
             if (!cancelled) setCustomerLoading(false);
           });
         return () => { cancelled = true; };
       }, [authUser?.id]);
