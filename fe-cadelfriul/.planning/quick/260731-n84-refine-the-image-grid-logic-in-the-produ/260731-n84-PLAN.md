<objective>
Refine the image grid logic in the Product Detail Page at `src/app/[locale]/(vetrina)/shop/[id]/page.tsx` so the desktop gallery (currently a fixed `md:grid-cols-[2fr_1fr]` layout at `h-[600px]`) renders per image count, exactly as specified:

- **1 image** → full width, `h-[500px]` (chosen over `aspect-[4/3]` for height consistency with the 2-image case's "same height h-[500px]")
- **Exactly 2 images** → `grid-cols-2`, each image `h-[500px]`
- **3+ images** → bento grid: first image `col-span-2 row-span-2`, remaining images auto-stack in the column(s) next to it; the grid maximizes to **3** visible images (3 total) or **5** (4+ total); anything beyond 5 goes behind the "Show all photos" button
- Every image wrapper: `overflow-hidden rounded-xl`; images `object-cover` (via the existing `GalleryImage` `fill` + `object-cover` pattern, which is equivalent to `w-full h-full object-cover`)

Purpose: Products carry 1–many images; the current layout stretches a single image into an oversized column and always shows a redundant "Show all photos" button even when every image is already visible. The count-based grid is the specified refinement and keeps the gallery height consistent (`h-[500px]`) across all layouts.

Output: Refactored desktop gallery (count-driven, bento capped at 5, conditional Show all photos button on both desktop and mobile) + 4 layout tests proving the grid classes. Mobile snap carousel, lightbox, and all buy-section logic remain untouched.

**Implementation notes (locked decisions):**
- **Height:** `h-[500px]` for the 1-image block and both 2-image cells; the 3+ bento container is `h-[500px]` with `grid-rows-2` (each row ≈ 250px, so the `row-span-2` first image is 500px tall — same height as the other layouts).
- **Bento grid columns:** exactly 3 images → `grid-cols-3` (first `col-span-2 row-span-2` + 2 stacked in col 3); 4+ images → `grid-cols-4` (stacked pair in col 3 + second stacked pair in col 4 = 5 visible max). With exactly 4 images, the 4th gets `row-span-2` so the last column reads as one tall strip instead of leaving an empty cell.
- **"Show all photos" button:** rendered only when hidden images exist (`count > 5`), on both desktop and mobile. With 1–5 images every photo is already visible → no button.
- **`GalleryImage` sub-component unchanged** (`fill` + `object-cover` + per-image `onError` fallback). Wrapper divs carry `overflow-hidden rounded-xl`.
- **Mobile:** snap carousel + arrows + dots untouched; only its "Show all photos" button becomes conditional.
- **Edge case count === 0:** render a muted `h-[500px]` placeholder block (ImageOff icon) instead of passing `undefined` src to `next/image` (which throws) — same fallback style as `GalleryImage`'s error state.
- **Alt text pattern (unchanged):** first image `alt={product.name}`, subsequent `alt={`${product.name} photo ${i + 1}`}`.
