## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `toBeDefined()` passes vacuously for `null` query results**
- **Found during:** Task 2 (RED verification)
- **Issue:** `expect(section.querySelector('[class*=...]')).toBeDefined()` does not fail when the element is absent: vitest/chai `toBeDefined()` only rejects `undefined`, but `querySelector` returns `null` on no-match. The tests were red, but for the wrong reason — the failure surfaced later at the class-containment assertions with a confusing `(undefined and string) is invalid` chai error, and the existence check was a no-op.
- **Fix:** Changed the four existence assertions to `expect(el).not.toBeNull()`, so each test now fails at the intended line with `expected null not to be null` when the layout class is missing.
- **Files modified:** `page.test.tsx`
- **Verification:** Re-ran the test file — all 4 new tests fail at the existence assertions (clean RED), 2 existing pass; after Task 1's rewrite all 6 pass.
