## Spacing Scale

All values on the 8-point grid. No exceptions for Phase 1.

| Token | px | rem (16px base) | Usage |
|-------|-----|-----------------|-------|
| xs | 4px | 0.25rem | Icon gaps, inline padding, fine adjustments |
| sm | 8px | 0.5rem | Compact element spacing, avatar gaps |
| md | 16px | 1rem | Default element spacing, card padding |
| lg | 24px | 1.5rem | Section padding, form field groups |
| xl | 32px | 2rem | Layout gaps between major sections |
| 2xl | 48px | 3rem | Major section breaks, hero bottom margin |
| 3xl | 64px | 4rem | Page-level spacing, top/bottom container padding |

**Exceptions:** None — Phase 1 does not require icon-only touch targets or non-standard spacing. The standard shadcn button sizes (`h-8`, `h-9`, `h-10`) are all multiples of 8px.

## Typography

Two font families, two weights, four sizes.

| Role | Font | Size | Weight | Line Height | CSS Variable |
|------|------|------|--------|-------------|--------------|
| Label / Small | Geist Sans | 14px | 400 (Regular) | 1.25 | `--font-sans` (utility class) |
| Body | Geist Sans | 16px | 400 (Regular) | 1.5 | `--font-sans` (default) |
| Heading (h2-h4) | Playfair Display | 24px | 600 (Semibold) | 1.2 | `--font-heading` |
| Hero / Display (h1) | Playfair Display | 56px | 600 (Semibold) | 1.1 | `--font-heading` |

**Desktop-first scaling:** 56px hero scales down to 36px on mobile (<768px). Heading (24px) scales down to 20px on mobile (<768px). Body remains 16px at all viewports. Use Tailwind responsive prefixes (`text-4xl md:text-5xl lg:text-6xl`) rather than manual media queries.

**Geist Mono** (`--font-geist-mono`) is already loaded — keep it for code blocks or technical UI only (not used in Phase 1 showcase pages).

## Color

Warm luxury rustic-chic palette. The existing `globals.css` has neutral (grayscale) defaults — these tokens must be overridden for the brand theme.

| Role | Value | CSS Variable | Usage |
|------|-------|--------------|-------|
| Dominant (60%) | `oklch(0.97 0.01 80)` — warm ivory | `--background`, `--card`, `--popover` | Page backgrounds, surface areas, modals |
| Secondary (30%) | `oklch(0.87 0.01 70)` — stone gray | `--secondary`, `--muted`, `--sidebar` | Cards, sidebar background, nav backgrounds, footer |
| Accent (10%) | `oklch(0.75 0.08 85)` — muted gold | `--accent`, `--primary` overlays | Primary buttons, active nav indicators, price highlights, decorative card borders |
| Foreground | `oklch(0.205 0.02 60)` — warm near-black | `--foreground`, `--card-foreground`, etc. | All body text, headings (over ivory/stone backgrounds) |
| Destructive | `oklch(0.577 0.245 27.325)` — red (keep shadcn default) | `--destructive` | Destructive actions only (none in Phase 1 — define for future phases) |

### Accent reserved for

The muted gold accent (`oklch(0.75 0.08 85)`) is reserved for these specific elements ONLY:

1. **Primary buttons** — Background fill on `variant="default"` buttons
2. **Active nav indicators** — Underline or dot on the currently active navigation link
3. **Price highlights** — Price display text on room/experience/product cards
4. **Decorative borders** — Top border accents on cards, section dividers, or frame decorations
5. **CTA hover states** — Hover/focus ring on interactive elements

The accent must NOT be used for: body copy, background fills (except buttons), heading text, form inputs, or decorative elements outside the approved list.

### Dark mode

Phase 1 does not implement dark mode. The `.dark` CSS variables in `globals.css` are left as shadcd neutral defaults — do not customize for Phase 1. Dark mode is out of scope until a future phase.

## Layout Contracts

### Route Group `(vetrina)` — Public Showcase

```
(vetrina)/
  _components/
    Header.tsx        ← full-width, sticky top, logo left, nav center, CTA right
    Footer.tsx        ← full-width, multi-column, dark stone background
  _styles/
    (none — Tailwind only)
  layout.tsx          ← Header + <main>{children}</main> + Footer
  page.tsx            ← HeroSection + sections (home page)
  rooms/page.tsx      ← RoomCard grid
  experiences/page.tsx← ExperienceCard grid
  products/page.tsx   ← ProductCard grid
  about/page.tsx      ← heritage storytelling layout
  contact/page.tsx    ← ContactMap + form placeholder
  loading.tsx         ← Skeleton layout matching page structure
  error.tsx           ← "Something went wrong" + "Please try refreshing the page"
  not-found.tsx       ← "Page Not Found" / "The page you're looking for doesn't exist" / "Return Home"
```

**Header spec:**
- Sticky top, `h-16` (64px), white/ivory background
- Logo left, desktop nav links center, "Explore Our Resort" CTA button right
- Mobile: hamburger menu (Lucide `Menu` icon) → sheet/slide-out nav
- Active page indicator: subtle gold underline via accent color

**Footer spec:**
- Stone gray background (`oklch(0.87 0.01 70)`)
- 3-4 columns: About / Quick Links / Contact / Social
- Bottom bar: copyright line

### Route Group `(auth)` — Authentication

```
(auth)/
  _components/
    AuthLayout.tsx    ← centered card, max-w-md, logo above form
  layout.tsx          ← AuthLayout wrapper
  login/page.tsx      ← email/password form (static placeholder)
  register/page.tsx   ← name, email, password, confirm form (static placeholder)
  reset-password/page.tsx ← email form (static placeholder)
  loading.tsx         ← minimal skeleton
  error.tsx           ← clean error state (no header/footer)
  not-found.tsx       ← clean 404 (no header/footer)
```

**Auth layout spec:**
- No Header or Footer — clean, minimal
- Centered vertically + horizontally, `max-w-md` card
- Logo or resort emblem above form
- "Ca' Del Friul" subtle watermark or brand mark in background

### Route Group `(dashboard)` — Customer Dashboard

```
(dashboard)/
  _components/
    SidebarNav.tsx    ← vertical nav, user avatar/name top
    DashboardLayout.tsx ← SidebarNav + main content area
  layout.tsx          ← DashboardLayout wrapper
  page.tsx            ← Dashboard overview / welcome (static)
  profile/page.tsx    ← profile edit form (static placeholder)
  addresses/page.tsx  ← address book (static placeholder)
  orders/page.tsx     ← order history table (static placeholder)
  reservations/page.tsx ← reservation list (static placeholder)
  loading.tsx         ← sidebar + content skeleton
  error.tsx           ← error with sidebar preserved
  not-found.tsx       ← 404 with sidebar preserved
```

**Dashboard layout spec:**
- Desktop: fixed sidebar 240px-280px wide left, fluid main content right
- Mobile: sidebar collapses to hamburger menu
- Sidebar: user avatar + name at top, nav links below, "Logout" at bottom (non-functional in Phase 1)

## Accessibility Requirements (Phase 1)

- All interactive elements must be keyboard-focusable (native `<button>`, `<a>`, `<input>`)
- Skip-to-content link as first focusable element in each layout
- Color contrast: body text (#1a1a1a on #f7f4ed) passes WCAG AA (ratio ~12:1). Gold accent on white for buttons needs verification — ensure `oklch(0.75 0.08 85)` on white (oklch(0.97 0.01 80)) meets 4.5:1. If not, darken gold slightly.
- Alt text on all decorative and informational images
- ARIA labels on icon-only buttons (mobile menu toggle, etc.)
- Focus-visible ring on all interactive elements (shadcn provides this)
